# Gravity

Интерактивная WebGL 2 демка, вдохновлённая [Krea](https://www.krea.ai/). Независимый визуальный эксперимент: звёзды и галактики движутся к камере, объёмная линза искажает свет вокруг поля ввода.

**[Открыть демку](https://zhenchur.github.io/krea-gravity-demo/)**

## Взаимодействие

- При загрузке появляются звёзды, затем чёрная дыра с фотонным кольцом и раскрывается поле ввода.
- Наведение приближает камеру, фокус увеличивает массу линзы до 180%.
- Отправка очищает текст и резко схлопывает поле по ширине за 0,4 с. В момент исчезновения из центра расходится круглая волна; после её завершения дыра появляется и раскрывается с базовой массой.
- Enter отправляет, Shift+Enter добавляет строку. Кнопки внизу позволяют повторить вступление и остановить анимацию.
- На мобильном поле учитывает видимую область при появлении клавиатуры. Системное уменьшение движения отключает вступление.

Поле не подключено к AI или серверу: введённый текст никуда не отправляется. Кнопка «Настроить» внизу открывает панель управления массой, локальным усилением, звёздами, галактиками и скоростью. Также доступны сетка искажения, эффекты рамки и проверка одной звездой. «Сбросить» возвращает исходный пресет; перезагрузка тоже начинает с него. Версия с кольцом Эйнштейна и переключатель версий не публикуются.

## Запуск и проверка

Зависимостей и сборки нет. Из папки проекта:

```sh
python3 -m http.server 4173
```

Откройте `http://localhost:4173/`. Для математических и регрессионных проверок нужен Node.js:

```sh
node --test tests/*.test.cjs
```

GitHub Pages публикует корень основной ветки репозитория; `.nojekyll` включает раздачу статических файлов.

## Файлы

- `index.html` — интерфейс, шейдеры и рендерер.
- `mass-lens.js`, `mass-profiles.js`, `lens-calibration.js` — объёмная модель и нормировка массы.
- `lens-intro.js` — последовательность появления и раскрытия.
- `star-buckets.js` — распределение источников по глубинам и отсечение невидимых.
- `star-flow.js` — движение поля по трём осям и циклическое заполнение объёма.
- `mobile-viewport.js` — адаптация к мобильной клавиатуре.
- `render-policy.js` — ограничение FPS, мобильное качество и бюджет карт искажения.
- `tests/` — 37 проверок физической модели, глубины, анимации и границ источников.

Пресет: масса 48%, локальное усиление 3000% в зоне 25 px, звёзды 31%, крупные звёзды 6%, 176 галактик, однородность 0%, скорость 2×. Начальные настройки задаются в `settingsDefault` внутри `index.html`; в демке их можно менять через панель управления. Распределение массы фиксировано: «Исходный объём».

Направление задаётся числовыми коэффициентами X/Y/Z от −1 до 1. X положительный — вправо, Y — вверх, Z — к камере; отрицательное значение меняет направление. Коэффициенты независимы и не нормализуются: `1 / 0.3 / 0` перемещает поле вправо с вертикальной составляющей 30%. `0 / 0 / 0` останавливает перенос поля, сохраняя эффекты интерфейса; начальный разлёт остаётся. Общий темп задаёт «Скорость». Исходное направление — `0.5 / 0.5 / 1`. Изменение осей сохраняет текущие позиции; «Сбросить» возвращает исходное направление, а повтор вступления также обнуляет накопленное перемещение.

## Производительность

Карты отклонения света рассчитываются при изменении геометрии и затем переиспользуются. Они хранят два канала RG32F вместо RGBA32F: точность остаётся 32-битной, память карт сокращена вдвое. При viewport 1280×720 основные карты занимают 15,2 MiB вместо 30,4 MiB. Цвет звёзд по-прежнему хранится в RGBA16F; количество источников не снижено.

Пиксели глубоко под непрозрачным полем исключены из дорогого расчёта линзы. Четырёхпиксельный запас сохраняет производные и сглаживание на видимой границе. После вступления прекращаются повторные записи неизменившейся геометрии и ARIA-атрибутов. Анимация приостанавливается в скрытой вкладке и вне видимости.

Частота отрисовки ограничена 60 FPS, включая дисплеи 120/144 Гц. Все анимации считают прошедшее время, поэтому снижение FPS не замедляет движение, раскрытие формы и волну.

Только на мобильных устройствах фон начинает с DPR не выше 1,5. После четырёх секунд устойчивой просадки ниже 82% целевой частоты разрешение ступенчато снижается до 1,25 и 1; если этого недостаточно, включается предел 30 FPS. Выбранный уровень сохраняется до перезагрузки, чтобы избежать колебаний качества. DOM-текст и интерфейс не масштабируются. Узкое окно компьютера не включает мобильный режим; на компьютерах сохраняется прежний DPR до 2.

Основная карта ограничена бюджетом 82 944 ячеек на слой. При размере сцены 390×844 её GPU-хранилище сокращается с 58,4 до 15,1 MiB (примерно на 74%), CPU-копии сокращаются в той же пропорции. После раскрытия формы карты вступления заменяются пустой текстурой 1×1: в этом размере освобождается около 87 MiB GPU-хранилища. Повтор вступления заново подготавливает карты.

Проверены 36 Node-тестов, мобильный режим с искусственными просадками кадров, освобождение/повторное создание карт в WebGL и отправка с возвратом массы. Эти проверки не заменяют замер FPS и нагрева на физическом телефоне.

Это визуальная модель слабого гравитационного поля с отдельными художественными эффектами. Фотонное кольцо декоративное; полноценная релятивистская динамика чёрной дыры не моделируется.

Отправка: поле очищается и теряет фокус, за 0,4 с резко сокращается по ширине с сохранением высоты почти до самого исчезновения; остаётся скрытым до окончания круглой волны (1,9 с), проявляется за 0,45 с и раскрывается за 1 с. Заголовок и звёздное поле сохраняются. Цикл не зависит от скорости/паузы звёзд, повторная отправка до завершения заблокирована. Круглая волна запускается из точки схлопывания точно в момент исчезновения, без прямоугольного контура. Временные карты линзы освобождаются после раскрытия.

При первоначальном рождении чёрной дыры (и повторе вступления) от её круглого горизонта проходит короткая волна искажения: 0,65 с, быстрое затухание, без светящейся обводки. Она использует тот же проход шейдера; фотонное кольцо дыры сохраняется.
